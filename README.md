# byoe-ecosystem

Ecosystem-level coordination for the `@interop/*` / BYOE repos: knowledge
that belongs to the ecosystem rather than to any one repo.

- [ECOSYSTEM.md](ECOSYSTEM.md) -- the one-page map: layer/dependency graph,
  specs and their implementations, which document is authoritative for
  what, and where a given kind of change goes.
- [LEARNINGS.md](LEARNINGS.md) -- durable cross-repo invariants, gotchas,
  and process recipes, plus the routing table to where each convention is
  canonical.

Per-repo conventions (roadmap schema, releasing, code style, decision
records) stay canonical in
[isomorphic-lib-template](https://github.com/interop-alliance/isomorphic-lib-template);
this repo routes to them, it does not duplicate them.
